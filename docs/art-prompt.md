# アイコンの依頼文

ChatGPT に投げる。名前の「Ice Ball」にかけて、ウイスキー用の透明な丸氷を主役にし、
アプリの働き（メニューバーを角丸の形にする）を、丸氷に重ねた角丸の帯で示す。2026-11-27 に本人が決めた。

## 1通目

```text
macOS のアプリアイコンの原画を1枚、画像で生成してください。

アプリ名は Ice Ball。Mac の画面上端のメニューバーを、角の丸い形に変えて見せるアプリです。名前にかけて「ウイスキー用の透明な丸氷」が主役です。

- 形式: 正方形 1024×1024。背景は四隅まで塗り切った正方形にしてください。角丸は付けないでください（こちらで付けます）。透明な部分は作らないでください
- 主役1: 透明で澄んだ、まん丸の氷の球を1つ、中央に大きく。ウイスキーの丸氷のように、淡い水色の透明感と、白いハイライトを左上に1つ
- 主役2: 氷の球の上の方に、横長で両端が丸いカプセル形の帯を1本、球の幅より少し広く横切るように重ねる。Mac のメニューバーを角丸にした形です。帯は半透明のすりガラス風の白で、太くはっきり
- 画風: フラットなベクター風。太い面で形を取り、細い線や細かい描き込みはしない。陰影はごく淡く
- 背景: 深い藍色（#1B2747 前後）の単色、またはごく淡いグラデーション
- 余白: 球と帯の全体が、外周15〜20%の余白の内側に収まるように。どこも端で切らない
- 文字、ロゴ、グラス、ウイスキー、水滴、床の影、枠などは一切入れない
- 要素は氷の球・帯・背景だけ

16px まで小さくしても「濃い地に丸い氷、その上に角丸の帯」と分かることが一番大事です。
```

1通目の絵は、帯が球からはみ出して帽子のつばに見え、球もシャボン玉に見えた。本人も「ダサい」。

## 2通目（同じ会話で続けて）

```text
方向を変えて、もう1枚生成してください。前の絵は、帯が球の外へはみ出して帽子のつばに見え、球も氷ではなくシャボン玉に見えました。

- 形式は前と同じ（正方形 1024×1024、四隅まで塗り切る、角丸なし、透明部分なし）
- 主役: ウイスキーのグラスに入れる、本物らしい透明な丸氷を1つ、中央に大きく。澄んだ氷の質感、縁の屈折、内側のわずかな白い気泡や細いひびで「氷」だと分かるように。シャボン玉のような虹色や薄い膜の表現はしない
- 丸氷の中: 球の上から3分の1あたりに、横長で両端が丸いカプセル形（Mac のメニューバーを角丸にした形）が、氷の内側に彫り込まれたように白く浮かんで見える。カプセルは球の輪郭の内側に完全に収め、外へはみ出さない。幅は球の7割ほど、太さははっきり分かる程度
- 画風: フラットすぎない、上品な半立体。光は左上から。細かすぎる描き込みはしない
- 背景: 深い藍色（#1B2747 前後）から少し明るい藍への、ごく淡いグラデーション
- 球の真下にごく淡い青い光の反射を少しだけ。床や影の形は描かない
- 余白: 球全体が外周15〜20%の余白の内側に収まるように
- 文字、ロゴ、グラス、ウイスキー、水滴、枠は一切入れない

16px まで小さくしても「濃い地に丸い氷、その中に角丸の白い帯」と分かることが一番大事です。
```

2通目を採った（1254×1254、透過なし）。16px でも「濃い地に丸い氷、中に白い帯」が残る。原画は `assets/icon-source.png`、角丸と余白は `Tools/make-icon.py` で付ける。
